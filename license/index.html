数据与出处

盗天机是免费的在线占卜站。本页列出本站使用的数据来源与许可证。所有排盘计算均在你的浏览器本地完成。

术数数据

本站的解梦、六爻、八字、紫微斗数等术数数据，来自开源项目 comprehensive-shushu-engine（wang-er-1-2003），该项目将 35 个体系的古籍原文逐句数字化为 JSON 数据。本站按 GNU 通用公共许可证第三版（GPL-3.0）使用这些数据。

GitHub 仓库：wang-er-1-2003/comprehensive-shushu-engine

许可证全文（GPL-3.0）：LICENSE.txt

本站源码

本站全部代码已开源（GPL-3.0），包括 34 个占卜工具与 AI 解读后端。

GitHub 仓库：OrbitingX/daotianji

农历换算

公历与农历换算使用 lunar-javascript（6tail，MIT 许可证）。

梅花解卦参考

梅花易数的 64 卦、384 爻辞等解卦参考资料，来自开源项目 muyen/meihua-yishu。

本站说明

本站所有工具均为静态页面，不收集、不上传你的输入。传统术数仅供参考，不构成决策依据。
