印度合盘：免费配对与使用常见问题

总分 36 分怎么看？多少分算好？

按通行分段：0–17 分不宜，18–24 分一般，25–32 分良好，33–36 分极佳。这是传统婚配常用的参考分段，不是科学测量；分数只看月亮星座与出生宿，不看太阳、金星、升点与大运，低分也不等于关系注定不好。

「本人」「对方」和传统婚配里的男方、女方怎么对应？

传统 Ashtakoota 是有方向的：Varna 看男方层级是否不低于女方，Vashya 与 Bhakoot 的查表也分男女方向。本页把「本人」当作男方（新郎）一侧、「对方」当作女方（新娘）一侧来计分；如果实际性别反过来，Varna 与 Vashya 的分数可能不同，Tara、Yoni、Graha Maitri、Gana、Bhakoot、Nadi 六项不受方向影响。交换两人位置重算一次即可对照。

月亮星座与出生宿是怎么算的？准吗？

与本站印度占星单盘完全相同的算法：回归黄经由 astronomy.browser.js 星历算出，减去 Lahiri 岁差近似值（23.85 +（年份 − 2000）× 0.01396 度）得到恒星黄经，再落入十二星座与二十七宿。岁差用的是线性近似，2000–2030 年间与真实 Lahiri 岁差的误差小于约 0.5°，宿的边界附近可能差一宿；要精确到角分请用专业星历软件核对。月亮每天约走 13°，出生时间误差几小时就可能算错宿。

Vashya 为什么人马座、摩羯座要看月亮度数？

人马座前 15°属人（Manava）、后 15°属四足（Chatushpada）；摩羯座前 15°属四足、后 15°属水生（Jalachara）。这是《Muhurta Chintamani》的分法，本页按月亮在星座内的实际度数划分，其余十个星座整座归属一组。查表以对方组为行、本人组为列，满分 2 分。

Bhakoot 得 0 分时，同主星为什么又给 7 分？

Bhakoot 只看两月亮星座的相对位置：2–12、6–8 宫位关系得 0 分，其余得 7 分。传统上若两星座主星相同（如白羊与天蝎同属火星、金牛与天秤同属金星、摩羯与水瓶同属土星），Bhakoot dosha 视为抵消，本页按常见计算器的处理给 7 分并在表中注明。是否抵消各家说法不一，这是本页的一处判断，见方法说明。

Yoni 的友好、敌对分级为什么各家表不一样？

十四种动物的友好与敌对分级在不同传承里略有出入，七对宿敌（马–水牛、象–狮、羊–猴、蛇–獴、犬–鹿、猫–鼠、牛–虎）是各家一致的 0 分。本页采用北印度 Parashari 常用表：同种 4 分，友好 3 分，中性 2 分，敌对 1 分，宿敌 0 分。换一张表可能差 1 分，总分以此为准。
